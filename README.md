# 確率過程 ランダムウォーク シミュレーション

1次元/2次元ランダムウォークを多粒子同時シミュレーションし、期待値・分散の収束と正規分布への近似をリアルタイムで可視化するツール。

## 機能
- 1Dモード: 複数粒子（10-100）の位置を時系列折れ線グラフで表示
- 2Dモード: Canvas上でランダムウォークの軌跡をトレース表示
- ステップ数スライダー（10-500）・粒子数スライダー（10-100）
- 平均・分散・理論分散のリアルタイム表示
- 最終位置ヒストグラムと正規分布近似オーバーレイ
- アニメーション実行・リセットボタン

## 技術
- Vanilla JS + Tailwind CSS CDN
- Canvas 2D API（メイントレース + 分布ヒストグラム）
- requestAnimationFrame によるスムーズアニメーション
